# Contact Management System (PF Project)
PF Project – Contact Management System in C++

This is a **C++ Contact Management System** developed as a **Programming Fundamentals (PF)** project.

## Features
- User Signup & Login
- Create contacts
- Display all contacts
- Search contacts
- Edit contacts
- Delete contacts
- File handling for storing data

## Technologies Used
- C++
- File Handling
- Structures
- Functions

## How to Run
1. Open in Dev C++ / CodeBlocks / Visual Studio
2. Compile and run `main.cpp`
