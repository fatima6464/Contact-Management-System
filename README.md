# 📇 Contact Management System

A console-based **Contact Management System** built in **C++**, developed as a Programming Fundamentals (PF) project during my first semester of university. This project focuses on core C++ concepts like structures, file handling, and modular functions to build a functional CRUD application.

## 📋 Overview

This application allows users to securely manage a personal contact list — from creating and editing entries to searching and deleting them — with all data persisted to disk using file handling.

## ✨ Features

- 🔐 **User Authentication** — Signup and login system
- ➕ **Create Contacts** — Add new contact entries
- 📃 **View Contacts** — Display all saved contacts
- 🔍 **Search Contacts** — Find contacts quickly
- ✏️ **Edit Contacts** — Update existing contact details
- 🗑️ **Delete Contacts** — Remove contacts from the list
- 💾 **Persistent Storage** — Data saved via file handling (no database required)

## 🚀 How to Run

1. Clone this repository:
```bash
   git clone https://github.com/yourusername/contact-management-system.git
```
2. Open the project in **Dev C++**, **Code::Blocks**, or **Visual Studio**
3. Compile and run `main.cpp`
4. Sign up / log in, and start managing your contacts!
